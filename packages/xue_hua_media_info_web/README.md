# xue_hua_media_info_web

The Web implementation of [`xue_hua_media_info`](https://pub.dev/packages/xue_hua_media_info).
[`xue_hua_media_info`](https://pub.dev/packages/xue_hua_media_info) 插件的 Web 实现。

Pure Dart: JPEG APP1 EXIF, PNG tEXt, and MP4/MOV `moov`. `MediaSource.file` is
not supported in the browser (`unsupported`). HEIC, TIFF, MKV/WebM throw
`unsupportedFormat`.

纯 Dart 实现：JPEG APP1 EXIF、PNG tEXt、MP4/MOV `moov`。浏览器不支持
`MediaSource.file`（`unsupported`）。HEIC、TIFF、MKV/WebM 抛 `unsupportedFormat`。

## Usage / 用法

This package is [endorsed](https://flutter.dev/to/endorsed-federated-plugin),
which means you can simply use `xue_hua_media_info` normally. This package will
be automatically included in your app when you do, so you do not need to add it
to your `pubspec.yaml`.

本包是 `xue_hua_media_info` 的官方背书实现：直接依赖 `xue_hua_media_info` 即可自动引入，
无需在 `pubspec.yaml` 中单独添加。
